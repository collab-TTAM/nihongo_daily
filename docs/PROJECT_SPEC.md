# PROJECT SPEC — Nihongo Daily

## Outcome
Personal-first Japanese learning app for JLPT N5 + N4, optimized for a 120-minute daily study routine on laptop and iPhone, with multi-device sync and AI conversation practice.

## Core modules
- Authentication and account sync
- Daily Plan (120 minutes)
- Vocabulary: Kanji, reading, Vietnamese meaning, usage context, examples, audio
- Kanji: readings, meaning, stroke order, tracing, free writing, scoring
- Grammar: pattern, Vietnamese explanation, usage, examples, common mistakes
- SRS review
- Quiz
- AI Tutor
- AI voice conversation
- Learning-error tracking and weak-point detection
- Progress dashboard

## Daily plan default
- SRS 20 min
- Vocabulary 15 min
- Kanji 20 min
- Grammar 15 min
- Listening/Reading 15 min
- AI Conversation 25 min
- Quiz/Review 10 min

## Initial release
Personal Alpha: N5 + N4, Web/Windows first, iPhone-ready architecture. Database must already support N3/N2/N1.

## Definition of Done
A feature is done only when it builds, critical logic has tests, shared contracts are respected, no secrets are committed, loading/error/empty states are handled, and documentation is updated.
